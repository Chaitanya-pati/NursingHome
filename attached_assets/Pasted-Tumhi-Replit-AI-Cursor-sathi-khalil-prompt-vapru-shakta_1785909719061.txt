> **Feature: User Assignment on Helper Page**
>
> In the **Nursing Home App**, update **only the existing Helper page**.

>

>      * Allow selecting one existing user and assign it to the helper.

>
>      * Option/button to create a new user directly from the popup.

>    * Allow changing the assignment to another existing user.

> 5. Prevent assigning the same user to multiple helpers (unless the system already supports multiple assignments).
> 6. Show a success message after assignment/update.
>
