ATTENDANCE FLOW

Employee Check In:
1. Employee logs in and clicks the existing "Check In" button.
2. Automatically capture:
   - GPS Latitude
   - GPS Longitude
   - GPS Accuracy
3. Send the location data to the backend.
4. Backend must:
   - Record SERVER TIMESTAMP (never browser/device time)
   - Perform reverse geocoding
   - Convert GPS coordinates into a readable address
   - Create a new attendance record
   - Set Status = "Pending Approval"

Employee Check Out:
1. Employee clicks the existing "Check Out" button.
2. Automatically capture GPS location again.
3. Send GPS data to the backend.
4. Backend must:
   - Record SERVER TIMESTAMP
   - Perform reverse geocoding
   - Update the same attendance record
   - Keep Status = "Pending Approval"

MANAGER APPROVAL

Create a Manager Attendance Approval screen (or extend the existing attendance management page only).

Display:
- Employee Name

- Check Out Time

- Check In Address
- Check Out Address
- Check In Latitude

- Check Out Longitude
- GPS Accuracy
- Current Status

Manager Actions:
- Approve
- Reject
- Optional Remarks

- Status = Approved
- Calculate Working Hours automatically
- Save Approval Timestamp (SERVER TIME)
- Save Approved By

When Rejected:

- Save Manager Remarks
- Save Approval Timestamp
- Save Approved By
